# Аттестация • Excel для Android

Android-версия excel_processor.py. Обработка выполняется на телефоне. APK собирает GitHub Actions: устанавливать SDK или Java на компьютер не нужно.

## Как пользоваться

1. Выберите несколько Excel/CSV-файлов или папку. Исходные файлы не изменяются.
2. Нажмите «Прочитать столбцы и группы первого файла» и выберите нужные столбцы. После изменения столбца сортировки повторите чтение для обновления списка групп.
3. Настройте префиксы по диапазонам или по количеству вопросов в группе Savol ID. При необходимости включите пол и баллы с коэффициентом.
4. Нажмите «Обработать и создать ZIP».
5. Сохраните ZIP либо Excel-файлы в выбранную папку.
6. Для отправки используйте «Отправить ZIP», «Отправить все Excel-файлы» или кнопку отдельного результата. В меню Android выберите установленный Telegram, затем чат и подтвердите отправку.

ZIP содержит все успешно созданные Excel-файлы текущего запуска. Ошибки отображаются отдельно. Одинаковые имена получают числовой суффикс. Сохраняются настройки, список импортированных файлов и результаты последнего запуска. Бот и токен Telegram не нужны.

## Скачать APK

В репозитории откройте **Actions → Build Android APK**. Сборка запускается при обновлении main, также доступна **Run workflow**.
После успешной сборки скачайте **Attestation-Excel-APK** из раздела **Artifacts**. Распакуйте архив и установите **Attestation-Excel.apk** на телефон. В архиве есть SHA-256 и снимок экрана эмулятора.

Это отладочный APK для проверки и личного использования. Для распространения и последующих обновлений с постоянной подписью потребуется релизный ключ. Облачный runner создаёт временную отладочную подпись; разные сборки могут потребовать переустановки.

## Совместимость

- Android 7.0+; 64-битные ARM-телефоны (arm64-v8a) и эмулятор x86_64. 32-битные устройства не включены.
- Вход: .xlsx, .xlsm, .xls, UTF-8 .csv; выход: .xlsx. Макросы исходных книг не переносятся.
- Обработка и ZIP работают без интернета. Для отправки нужен установленный Telegram.
- Пока идёт обработка, держите приложение открытым. Поворот экрана поддерживается; продолжение после принудительного закрытия процесса не предусмотрено.
- Скорость и предельный размер таблицы зависят от памяти телефона; нужны проверки на реальных файлах.
- Используйте сохранение в папку или ZIP для постоянной копии: Android удаляет внутренние данные при удалении приложения.

## Код и проверки

- app/src/main/python/processor_core.py — ядро, извлечённое без изменения алгоритма из оригинала.
- mobile_api.py — пакетная обработка, поддержка старого .xls через xlrd, проверка настроек, уникальные имена и ZIP.
- app/src/main/java/uz/attestation/excel/ — интерфейс, работа с документами, обмен файлами, фоновая обработка.
- reference/excel_processor.py — оригинал для сравнения; не включается в APK.
- tests/test_processing.py — сравнение ячеек, оформления, баллов и листа ошибок с оригиналом; группы, коллизии имён, ZIP, повторные запуски.
- AppSmokeTest.java — обработка на Android, проверка ZIP и FileProvider, запуск и пересоздание экрана.

Алгоритм оригинала сохранён, включая норму по наиболее частому числу строк и первый ответ при повторах вопроса. Все тестовые данные синтетические.

CI: Gradle 8.11.1, AGP 8.9.2, Java 17, Chaquopy 17, Python 3.13. Android-библиотеки: pandas 2.1.3, NumPy 1.26.2, openpyxl 3.1.5, xlrd 2.0.1. Хостовые тесты используют pandas 2.2.3 / NumPy 2.2.5, а эмулятор проверяет библиотеки внутри APK.

Документация: [Chaquopy](https://chaquo.com/chaquopy/doc/current/android.html), [передача файлов Android](https://developer.android.com/training/secure-file-sharing).
